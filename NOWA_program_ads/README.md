# NOWA — program_v1 ads

Сопоставление текстов и креативов для кампании «соберём программу» — тот же набор из 7 «дверей» (болей), что и в wave1, но теперь на каждую дверь/вариант A/B — **два оффера**:

- **За 1 ₽** → `https://now-a.life/program` (микро-платёж, возврат 7 дней)
- **Бесплатно на месяц** → `https://now-a.life/program-free` (без карты, автосписаний нет)

Итого 7 дверей × 2 варианта × 2 оффера = **28 объявлений**.

- **Источник текстов:** `NOWA_teksty_programma.docx`
- **Источник картинок:** `NOWA_program_creatives_updated_v2/` (Downloads)
- **Единый файл сопоставления:** [`ads_mapping.json`](./ads_mapping.json)

## Структура

```
NOWA_program_ads/
├── ads_mapping.json     ← сопоставление текст + картинка + 2 оффера на каждый из 14 креативов
├── README.md
└── creatives/
    ├── 01_son-1_A.png ... 14_head-1_B.png   (те же 14 боль-хуков, обновлённый дизайн с бейджем "30 дней")
```

Изображения переиспользуют боль-хуки wave1, но макет обновлён — под заголовком теперь бейдж «программа на 30 дней» вместо door-specific CTA-кнопки (сама кнопка формируется в объявлении).

## Текст объявления (структура)

Основной текст = 2 общих боль-абзаца двери + абзац про квиз (5 вопросов → маршрут на 30 дней, специфичный для двери) + закрывающая строка оффера. Заголовок и кнопка «Подробнее» — из оффера.

## UTM-схема

- `utm_source=meta_{{site_source_name}}` — динамическая платформа показа с префиксом meta_ (как в wave1)
- `utm_medium` — **placeholder, не подтверждён**: `trial_1r` для оффера за 1₽, `lead_free` для бесплатного. Отражает разную экономику офферов (платный микро-чек vs лид без оплаты) — уточнить перед запуском в Meta.
- `utm_content=<door_id>_<A|B>_<1r|free>`
