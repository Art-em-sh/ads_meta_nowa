# NOWA — wave1 ads

Сопоставление текстов и креативов для первой волны объявлений Meta (7 «дверей» × варианты A/B).

- **Источник текстов:** `NOWA_тексты_объявления.docx`
- **Источник картинок:** `NOWA_wave1_creatives/` (Downloads)
- **Единый файл сопоставления:** [`ads_mapping.json`](./ads_mapping.json) — источник правды. Все поля объявления (заголовок, основной текст, кнопка, ссылка с UTM, картинка) собраны туда per-вариант.

## UTM-схема

- `utm_source={{site_source_name}}` — динамическая подстановка платформы показа (Meta: fb/ig/an/msg)
- `utm_medium=initiate_checkout` — кампания оптимизирована под событие InitiateCheckout
- `utm_content=<door_id>_<A|B>` — идентификатор конкретного креатива, из исходного документа

## Meta launch — статус

Кампания создана через Meta Ads MCP на основе этого сопоставления. Все детали (ID кампании/ad set/креативов/объявлений, таргетинг, известные ограничения) — в блоке `meta_launch` внутри [`ads_mapping.json`](./ads_mapping.json).

- Аккаунт: `207779728749375` (ads for pesonal, USD), Страница `Yoyogyoga` (1265724379948871 — та же, что и в живых продающих кампаниях NOWA)
- Кампания `120254516297970628` — CBO $50/день, цель OUTCOME_SALES, **PAUSED**
- Ad set `120254517336500628` — 1 группа на все 7 дверей × A/B (14 объявлений), таргетинг: Грузия/Азербайджан/Казахстан/Армения/Узбекистан/Киргизия/Таджикистан/Турция + Европа + Дубай/Бали, возраст 20–65, Украина исключена. **PAUSED**
- 14 креативов и 14 объявлений — все **PAUSED**, ничего не тратит бюджет
- Оптимизация: запрошен InitiateCheckout, но Meta API стабильно отклонял это событие (вероятно, не входит в приоритетные события Aggregated Event Measurement для now-a.life) — временно оптимизация на **Purchase**, нужно донастроить в Events Manager и пересоздать ad set
- Пхукет (Таиланд) исключён из гео — Meta блокирует city-level таргетинг в Таиланде для аудитории от 20 лет

### Исправлено после ревью (важно)

Первая версия содержала баг: UTM-параметры (включая динамический макрос `{{site_source_name}}`) были вписаны прямо в ссылку и буквально показывались как сырой текст в теле объявления. Исправлено:
- Видимый текст объявления теперь чистый, без URL
- UTM с макросом перенесены в `link_url` креатива (единственное доступное поле через этот инструментарий — поле `url_tags` на уровне объявления оказалось недоступно для редактирования через MCP)
- Итоговая ссылка с трекингом для каждого варианта — в поле `meta_link_url_with_utm` в JSON

Также в процессе первый ad set был автоматически удалён Meta (похоже на защиту от подозрительной активности при частых операциях создания/удаления подряд) — пересоздан заново, ID обновлён выше. Сам аккаунт не заблокирован.

Всё требует ручной активации в Ads Manager (или явной команды на активацию).
